## 👨‍💻 About Me

I'm a Seoul-based Software Engineer who cares first about the **problem and the product** — I'd rather explain *why* I chose a stack than just list what I know. Right now I'm deepening my native mobile craft at the **Apple Developer Academy (POSTECH, 5th Learner)**, building iOS apps with Swift/SwiftUI while continuing to ship full-stack work end to end.

> 문제 파악과 제품 이해도가 높고, 이해관계자 간 조율이 가능한 개발자를 지향합니다.

- 🍎 Building native iOS apps with **Swift & SwiftUI**, and shipping full-stack features with **Next.js, React, Spring Boot**.
- 🧠 I learn by going **problem → concept → why → alternatives/trade-offs → implementation → test**, and I default to official docs over shortcuts.
- 🔍 Currently job-hunting for **entry-level engineering roles**, drawing on hands-on project work in backend/API/data, mobile, and AI integrations.
- ✍️ Writing up what I learn — system design, backend trade-offs, and iOS notes — on **[Medium](https://medium.com/@hyojoon.dev)** and **Velog**.
- 💬 Ask me about: Swift/SwiftUI, Spring Boot & Kafka microservices, Next.js/React, and applied ML (function calling, recommendation/CTR models).
